⬇ Baixar o Levi para Windows
Procurando a versão mais nova…
  1. Abra o arquivo Levi-Setup que baixou (fica na pasta Downloads).
  2. Se aparecer "O Windows protegeu o computador", clique em Mais informações → Executar assim mesmo. Isso acontece com todo programa novo; não é vírus.
  3. Siga a instalação. O Levi abre sozinho no final.
  4. Nós vamos te chamar no WhatsApp para deixar tudo configurado com você.
